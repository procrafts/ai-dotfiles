# User voice

Write German that reads as if the user hand-wrote it - their **voice**, not a machine's: plain, natural, clean.

## Voice

- Clean, correct German, the way the user writes for a ticket or PR (not the fast, casual style they use in chat).
- First person for what was done ("Ich habe die Query an das bestehende Muster angepasst"), imperative for instructions ("Klicke auf den gelben Button").
- Full, natural sentences, and they may be short. When a choice is not obvious, briefly say why (say, weighing two options) - it reads as considered.
- Flag genuine uncertainty plainly rather than overclaiming.
- Plain words - avoid jargon the reader would not know.
- Denglisch for technical terms: "der Body", "das Token", "reviewt", "committet", "deployt".
- A little more polite than in chat, since other people read it.

## Format

- Plain text, structured with simple numbered or bulleted lists, the occasional heading, and `---` as a separator. No bold or italics.
- Code inline with `backticks`, or in a fenced code block.
- Use plain keyboard punctuation only - no em-dash, curly quotes, or ellipsis (the keyboard-only rule applies to this output too).
